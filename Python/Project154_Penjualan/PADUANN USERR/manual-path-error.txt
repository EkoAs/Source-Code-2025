pip is not recognized?


Panduan Solusi Error "PIP is not recognized"
Jika saat mengetik pip install muncul pesan error, itu karena Windows belum tahu di mana letak folder Python. Ikuti langkah langkah "Add to Path" manual berikut:
======================================================================================
Langkah 1: Mencari Lokasi Folder Python
Tekan tombol Windows + R di keyboard, ketik %appdata% lalu tekan Enter.

Kamu akan masuk ke folder Roaming. Klik tulisan AppData di bagian atas (address bar) untuk kembali satu tingkat.

Masuk ke folder: Local > Programs > Python > Python312 (angkanya bisa berbeda tergantung versi, misal Python310).

Di dalam folder Python tersebut, cari folder bernama Scripts.

Penting: Klik pada kolom alamat di bagian atas folder, lalu Copy alamat tersebut. (Contoh alamat: C:\Users\NamaKamu\AppData\Local\Programs\Python\Python312\Scripts)

====================================================================================
Langkah 2: Mendaftarkan ke System Environment
Klik tombol Start, ketik "env", lalu pilih "Edit the system environment variables".

Di jendela yang muncul, klik tombol Environment Variables (ada di pojok kanan bawah).

Di bagian User Variables (kotak atas), cari variabel bernama Path, lalu klik sekali dan klik tombol Edit.

Di jendela baru yang muncul, klik tombol New di sebelah kanan.

Paste alamat folder Scripts yang tadi kamu copy ke kolom kosong tersebut.

Klik OK di jendela tersebut.

Klik OK lagi di jendela Environment Variables.

Klik OK terakhir di jendela System Properties.

==========================================================================
Langkah 3: Verifikasi (Wajib Restart CMD)
Tutup semua jendela Command Prompt atau Terminal yang sedang terbuka.

Buka CMD baru.

Ketik perintah: pip --version

Jika muncul tulisan seperti pip 24.x.x from ..., berarti BERHASIL!

Alternatif Tanpa Ribet (Solusi Instan)

Gunakan python -m pip di depan setiap instalasi. Contoh:
python -m pip install flask flask-cors
Perintah ini biasanya langsung jalan selama Python-nya sudah terinstall, tanpa perlu setting Path manual.
