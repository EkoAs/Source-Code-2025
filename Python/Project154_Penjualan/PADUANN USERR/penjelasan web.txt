2. Cara Kerja Hubungan Antar File Kamu bisa jelasin alur "Telepon-teleponan" antar file ini:
A. Saat Halaman Utama Dibuka (index.php ↔ app.py)Di index.php, ada syntax:$response = file_get_contents("http://127.0.0.1:5000/api/produk"); Baris ini adalah saat PHP "menelpon" Python. 
PHP minta data barang terbaru ke alamat (URL) yang disediakan Python.
Di app.py, syntax ini yang menjawab:@home_bp.route('/api/produk') Ini disebut Endpoint API. 
Python nerima telpon tadi, lalu nyuruh file barang.py buat ambil data di file .txt, terus dikirimin balik ke PHP dalam format JSON.


===================================================================================================================================================================================
B.  Saat Transaksi (index.php → checkout.php → receipt.php)Dari index.php ke checkout.php:Syntax: <a href="checkout.php?id=<?php echo $p['id']; ?>">
 Kita pake metode GET. ID barang dikirim lewat URL biar halaman checkout tau barang mana yang mau dibeli.
Dari checkout.php ke receipt.php:Syntax: <form action="receipt.php" method="POST">Penjelasan: Kita pake metode POST. 
Semua data (nama barang, total harga, metode bayar) dikirim secara "tersembunyi" ke halaman struk biar aman.

3. Penjelasan Syntax Penting CORS(app) di app.py:Kenapa ada ini? Secara standar, Python nggak boleh kasih data ke aplikasi lain (PHP).
 CORS ini adalah "Surat Izin" agar PHP di localhost boleh ambil data dari Python.json_decode($response, true) di PHP:
Fungsinya? Data dari Python datengnya dalam bentuk string (teks). Syntax ini ngerubah teks itu jadi Array biar PHP bisa nampilin nama baju dan harganya satu-satu pake foreach.number_format($harga, 0, ',', '.')
 di PHP:Fungsinya? Biar tampilan harganya profesional. Ngerubah angka polos 150000 jadi ada titik ribuan 150.000.
